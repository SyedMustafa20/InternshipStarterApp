You can setup and utilize this starter project by:
Cloning the repository using the link into your android studio.

After cloning the repository the project will be ready to run.

Project description:
This project utilizes android api 12 for displaying a built-in splash screen.
It has a simple HomeScreen Activity which displays a random quote from a hardcoded list, once the button is clicked.
